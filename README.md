# Student Management System

## Project Overview
A desktop application developed using Python Tkinter and PostgreSQL to manage student records.

## Technologies Used
- Python
- Tkinter
- PostgreSQL
- pgAdmin 4
- psycopg2

## Features
- Add student records
- View student records
- Search students by ID or name
- Update student details
- Delete student records

## Database Details
- Database: student_db
- Table: students

## How to Run
1. Install Python and PostgreSQL.
2. Install the required package:
   pip install psycopg2-binary
3. Create the student_db database and students table.
4. Configure the database connection in app.py.
5. Run the application:
   python app.py

## Project Objective
To simplify student record management using a graphical interface and a relational database.
